# Sacred Timeline — MCU 映画タイムライン

マーベル・シネマティック・ユニバース（MCU）の映画を「公開順」と「時系列順」で見られる、TVA 風の非公式ファンサイトです。

https://iwatanabe-7.github.io/marvel-movie-site/

## 機能
- 公開順 / 時系列順の切り替え、フェーズ別の絞り込み
- 次回公開作のカウントダウン
- 別ユニバース作品は神聖時間軸から分岐して表示

## 作品の追加・修正
`data.js` の `MOVIES` を編集してください。

## クレジット
ポスター画像は [TMDB](https://www.themoviedb.org/) のものを使用しています。本サイトは TMDB の承認・認定を受けたものではありません。
